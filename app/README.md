# FinSight Application — Planned

**Status: No application source code has been added yet.** This folder is reserved for the future FinSight website, not an installed or deployed product.

## Intended first implementation

Sprint 6 recommends beginning with **secure accounts → stock search → reliable market-data retrieval → AI explanations → authenticated watchlists**, and adding stock comparisons and advanced charts once core functionality has been validated.

Before starting, the team must confirm the MVP scope, technology stack, database, permitted data provider and licensing, AI service and cost, security, and acceptance criteria. Do not commit API secrets or represent mock quotes as live prices.

The implementation tasks are recorded in [GitHub Issues](https://github.com/JustEmre12/FinSight/issues). Use the [project roadmap](../docs/ROADMAP.md), [requirements](../docs/REQUIREMENTS.md), [Sprint 6 object-oriented model](../docs/SPRINT6_OBJECT_ORIENTED_MODEL.md) and [contributing guide](../CONTRIBUTING.md).

There are no installation, build, test or deployment commands until an application stack and code exist.
