# Interactive FinSight Kanban

Open **index.html** locally in a browser to view a **read-only live Kanban** based on public GitHub Issues and their stage labels. It has search and priority filters, dynamic counts and direct links to tasks. It does **not** provide write access or drag-and-drop changes to GitHub.

The repository's Markdown snapshot lives at [docs/KANBAN.md](../docs/KANBAN.md). If GitHub Pages is configured by the repository owner, publish this repository's main branch/root, then access the board at the Pages URL ending in **/FinSight/board/**. GitHub Pages is **not automatically enabled** by adding this file.

For an actual editable native GitHub Projects board, create one from GitHub Projects in your browser with the seven statuses and add the existing repository Issues. The current connector does not expose Project creation.
