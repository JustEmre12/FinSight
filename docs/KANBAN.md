# FinSight Kanban — Full project synchronization (November 3, 2026)

**Snapshot:** 81 GitHub Issue records (excluding the merged PR), **55 open**, **26 closed**. **77 stage-tracked cards** across seven lanes. The 4 closed duplicate records are deliberately **excluded from this Kanban** so the same proposed work does not appear twice. Each Issue's live `stage:` label remains authoritative.

This is an **Issues-based Kanban snapshot**, not a native editable GitHub Projects board. The [interactive read-only board](../board/index.html) loads live public Issue labels when served. [Open Issues](https://github.com/JustEmre12/FinSight/issues).

**Status integrity:** "Done" means submitted planning/modeling deliverables or the separately verified **sample-data frontend merged in PR #69**. It does **not** imply live market data, secure auth, working backend, real AI model, a live database or approved deployment. "In Progress" placements for planning are **provisional** until team members confirm.

- **[Ready (13)](https://github.com/JustEmre12/FinSight/issues?q=label%3A%22stage%3Aready%22)** — Planned work with enough details for next action.
- **[In Progress (4)](https://github.com/JustEmre12/FinSight/issues?q=label%3A%22stage%3Ain-progress%22)** — Planning tasks provisionally in progress; verify actual owner activity.
- **[In Review (8)](https://github.com/JustEmre12/FinSight/issues?q=label%3A%22stage%3Ain-review%22)** — Team review or approval pending; not complete.

## How to maintain accurate status
1. Open the GitHub Issue; document deliverables, role confirmation, acceptance and source/PR link.
2. Move exactly one `stage:` label between stages; do not use closed duplicates as active cards.
3. Close actual implementation issues only after reviewed code, tested integration and full acceptance.
4. Keep source/approval blockers open until a genuine team decision. Sprint 6 **recommended** conditional design approval; this is not sign-off.
5. For an editable drag-and-drop Project, configure **GitHub Projects** separately; this repository contains Issues, labels and a read-only web view.
